# Second-Brain – Obsidian Vault

A clean, scalable **personal knowledge management (PKM)** vault built for:

- Daily thinking
    
- Long-term learning
    
- Projects & areas
    
- Git + mobile sync
    

This vault is intentionally **simple**, **numbered**, and **future-proof**.

## How to Use Each Folder

### `00-Inbox`

- Fast capture
    
- No structure
    
- Process later
    

**Rule:** Nothing stays here long-term.

---

### `01-Daily`

- One note per day
    
- Tasks, focus, reflection
    
- Links out to notes and projects
    

**Rule:** Daily notes are temporary context.

---

### `02-Notes`

#### `Fleeting/`

- Rough ideas
    
- Half-formed thoughts
    
- Short-lived
    

#### `Permanent/`

- One idea per note
    
- Clearly explained
    
- Linked to other notes
    

**Rule:** Permanent notes must stand alone.

---

### `03-Projects`

#### `Active/`

- Goal-oriented work
    
- Has tasks
    
- Has an end
    

#### `Archived/`

- Finished or paused projects
    

---

### `04-Areas`

- Ongoing responsibilities
    
- Never “done”
    
- Examples: Career, Health, Finance
    

---

### `05-Resources`

- External knowledge
    
- Books, articles, videos
    
- Always link resources to notes
    

---

### `06-Templates`

- Reusable note structures
    
- Daily, Note, Project templates
    
- Keep minimal
    

---

### `07-Canvas`

- Visual thinking
    
- System design
    
- Learning maps
    

**Rule:** Canvas connects ideas; Notes explain them.

---

### `08-Attachments`

- Images, PDFs, diagrams
    
- Git-safe storage
    

---

### `99-Archive`

- Old notes
    
- Inactive content
    
- Keeps vault clean
    

---

## Daily Workflow (Recommended)

1. Capture ideas → **Inbox**
    
2. Write daily note → **Daily**
    
3. Convert useful ideas → **Notes**
    
4. Track work → **Projects**
    
5. Review weekly → **Archive / Promote**

## Markdown Symbols Cheat Sheet

### Headings

```md
# Heading 1
## Heading 2
### Heading 3
```

---

### Bold / Italic

```md
**Bold**
*Italic*
***Bold Italic***
```

---

### Lists

```md
- Bullet item
- Another item

1. Numbered item
2. Another item
```

---

### Checkboxes (Tasks)

```md
- [ ] Task not done
- [x] Task done
```

---

### Links (Most Important in Obsidian)

#### Internal link (to another note)

```md
[[Spring Boot Transactions]]
```

#### Link with alias

```md
[[Spring Boot Transactions|Transactions]]
```

#### External link

```md
[Obsidian Website](https://obsidian.md)
```

## Git & Sync Notes

- This vault is Git-ready
    
- `.obsidian/workspace.json` is ignored
    
- Commit once per day
    
- Pull before editing on another device
    

---

## Guiding Principles

- One idea per note
    
- Link more than you write
    
- Folders are for **where**, links are for **meaning**
    
- Simplicity > complexity
